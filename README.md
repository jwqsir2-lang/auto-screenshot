# 自动截图（AutoScreenshot）

Android 应用：**后台常驻，每隔 1~15 分钟自动截取屏幕一张，存入一个文件夹**。适用于平板 / 电视（Android 7.0+）。

## 功能
- 定时截图：间隔在应用内填写，限制 1~15 分钟，默认 5 分钟。
- 保存位置：优先 `/sdcard/auto_screenshot/`；Android 10 以上若公共目录不可写，自动改存应用私有目录（连电脑可见），文件名 `shot_年月日_时分秒.jpg`。
- 不会被随便关闭：
  - 前台服务 + 常驻通知，系统不会轻易回收；
  - `START_STICKY`，被回收后自动重启；
  - 从最近任务划掉会自动重启服务；
  - **激活设备管理器后无法卸载**，禁用设备管理器时有二次确认；
  - 应用内「停止并退出」**必须输入密码**（默认 `1234`，可在应用内修改）。
- 开机 / 应用更新后自动打开界面提示重新授权。

## 使用步骤
1. 安装 APK，打开「自动截图」。
2. 填间隔分钟数，点「授权并开始后台截图」，在系统弹窗点「开始投屏 / 立即开始」。
3. 点「激活设备管理器（防卸载）」，系统设置里激活。
4. 想停掉时回应用点「停止并退出（需密码）」。

> Android 不允许后台重新申请录屏授权。如果服务被强制停止或重启了手机，通知会提示「授权已失效」，重新打开应用点一次「授权并开始」即可恢复。

## 编译
本机不需要任何 Android 环境，由 GitHub Actions 编译：

```
git push origin main
```

推送后 Actions 自动编译，在 Actions 页面对应 run 的 Artifacts 里下载 `autoscreenshot-release-apk`（**已用正式 keystore 签名的 release 包**，debug 签名会被杀毒软件误报）。
